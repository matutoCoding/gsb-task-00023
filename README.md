# 卷宗归类台

给档案室编目员使用的离线单页工具，用浏览器 `index.html` 即可打开。

## 使用

- 直接双击打开 `index.html`，或在本目录运行：
  `python3 -m http.server 8123`
  然后访问 `http://127.0.0.1:8123/index.html`。
- 数据保存在浏览器 `localStorage`，关闭页面后会恢复当前门类层和停在手上的待归卷宗。

## 规则

1. 档号格式为 `年度-保管期限码-门类码-四位顺序号`，如 `2026-Y-WS-0001`。
2. 每个门类固定占一层；待归卷宗按门类摆到对应架层。
3. 每层正式架最多 60 卷，第 61 卷起进入同层旁边暂存格。
4. 暂存格最多 30 卷；放满后不再接收新卷宗。
5. 正式架空位与暂存格卷宗同时存在时，只能先把暂存格顶部卷宗挪回正式架。
6. 卷宗从暂存格回正式架时，会保留并显示原暂存层号。
7. 卷宗调入其他门类时，会重排落脚层及其以下各层，并列出换位与未动项。
8. 卷宗摆入瞬间生成并锁定档号；之后改保管期限或门类代码，不影响旧档号。
9. 修改档号规矩中的年度前会要求确认；确认后所有已摆卷宗清空档号和位置，回到待归区重摆。
10. 年度重摆总览持续显示换位置、没动、新增已摆和仍待归的卷宗数量。

## 文件

- `index.html`：页面结构。
- `styles.css`：架层、格位和差异状态样式。
- `core.js`：纯业务状态机，可在 Node 中直接验证规则。
- `app.js`：浏览器交互、渲染和本地保存。
