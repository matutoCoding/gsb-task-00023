# 档案室编目员用的卷宗归类台

这是一个零依赖中文单页应用，直接用浏览器打开 `index.html` 即可使用，数据保存在当前浏览器的 `localStorage` 中。

## 使用

- 直接打开：双击 `index.html`，或在当前目录运行 `python3 -m http.server 8000` 后访问 `http://127.0.0.1:8000`。
- 先维护年度、保管期限、门类代码和门类顺序，保存后按 `年度-期限代码-门类代码-三位顺序号` 生成档号。
- 在待归区登记卷宗，选择“手上那一层”后逐卷或连续摆入。
- 每层最多60卷；第61卷起进入暂存格，暂存格满30卷后不再接收。
- 点击正式架上任一卷，可将它调入其他门类；落脚层及下方层位会连带重排并标记移动。
- 从暂存格挪回正式架时，卡片会持续展示它原来来源的层号。
- 已正式上架的卷宗立即锁定档号，之后改期限、门类代码或门类顺序都不会变更旧档号。
- 修改规则中的年度并确认后，已摆放卷宗全部回到待归区；重摆后在“重摆比对”中查看换位、未动和待重摆数量。
- 关闭页面后重新打开，会恢复当前手层和上次摆到的卷宗。

## 内置验收辅助

- “载入示例”：添加5卷不同门类和期限的待归卷宗。
- “加入95卷容量测试”：向第一层添加95卷，用于验证60卷入正式架、30卷入暂存格、5卷因暂存满而留在待归区。
- “清空重来”：删除本地存档并恢复初始规则。

## 文件

- `index.html`：页面结构。
- `styles.css`：工作台、层架、暂存格和状态标记样式。
- `app.js`：规则、档号、排架、调层重排、年度复位、位置比对和本地续存逻辑。
